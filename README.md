# Sijan — Personal portfolio

A responsive, static portfolio for Md. Ahasanul Banna Sijan, Data Entry Operator at Intelligent Image Management Ltd. Built with HTML, CSS, and JavaScript, with no build step or runtime dependencies.

## Customize social links

Edit `site.config.js` to change the LinkedIn URL or add Facebook, Instagram, X, and other social profiles. Empty URLs are hidden. Add a new object with a `label` and a full `https://` URL to include another platform. Social links update in both the introduction and contact section.

The email appears in `index.html` and `site.config.js`; update both when changing the contact address. Personal text and employment details can be edited directly in `index.html`.

## Hosting

Netlify publishes the repository root using `netlify.toml`. No build command is required. Google Fonts supplies Manrope and DM Sans, with sans-serif fallbacks if unavailable.
